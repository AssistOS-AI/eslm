# Corpus Engineering Prompt

Build streaming, content-addressed, reproducible TinyStories ingestion. Preserve source hashes, exact and near-duplicate analysis, deterministic splits, sentence/story statistics, lexical and template overlap reports, and protected split boundaries. Do not inspect final test content during development. Produce data manifests, data cards, contamination checks, and resource profiles. Any normalization that can change semantics must be versioned and reversible.
