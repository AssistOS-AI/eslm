# Performance Engineering Prompt

Optimize streaming ingestion, indexes, chart parsing, state updates, rule matching, caching, serialization, and deterministic parallelism without changing semantics. First establish profiles and correctness oracles. Report wall time, CPU/GPU time, peak RSS/VRAM, cache hit rates, artifact sizes, and asymptotic risks. Ensure smoke, pilot, and full profiles differ only by scale and budget, not by hidden algorithmic shortcuts. Preserve reproducibility across worker counts.
