# Probabilistic Scoring Prompt

Build a mathematically valid language-model distribution over arbitrary UTF-8 text. Define token/sample space, factorization, smoothing, backoff, latent structures, and normalization. A semantic reranker may be useful but must not be called a probability until normalized. Implement mass tests on finite projections, exact or bounded scoring, BPB/perplexity, continuation likelihood, calibration, and numerical stability. Compare lexical-only, grammar-only, semantic-reranked, and normalized-mixture ablations.
