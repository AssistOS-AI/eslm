# External benchmark data policy

This repository contains adapters and conversion instructions, not copies of third-party benchmark data. Each acquisition must record source URL, revision, license, file hash, and local visibility. Password-protected or agreement-gated datasets remain outside version control.

Derived prediction files may be published only when their source license permits. Test targets are never added to agent failure packets. External datasets are evaluation-only unless an experiment explicitly creates and labels a transfer-training regime.
