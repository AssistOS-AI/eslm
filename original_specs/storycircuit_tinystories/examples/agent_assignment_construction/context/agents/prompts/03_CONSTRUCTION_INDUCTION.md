# Construction Induction Prompt

Induce reusable weighted form–meaning constructions from raw or weakly annotated stories. Begin with observable spans, typed slots, lexical anchors, morphology, and candidate StoryIR fragments. Use anti-unification, clustering, MDL pruning, and counterexamples. Avoid one-rule-per-sentence memorization. Each construction requires positive examples, near misses, ambiguity behavior, probability/count evidence, and a provenance manifest. Evaluate text-to-IR fidelity and lexical/template OOD transfer.
