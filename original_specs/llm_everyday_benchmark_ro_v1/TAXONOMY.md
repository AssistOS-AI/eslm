# Taxonomie

| Familie | Ce verifică |
|---|---|
| Factualitate | cunoștințe generale stabile din geografie, știință, istorie, cultură, economie și tehnologie |
| Calcul și reasoning ușor | aritmetică, procente, timp, proporții, șiruri și ordine logică |
| Limbă | traducere, vocabular, antonime/sinonime, punctuație și formulare |
| Transformare de text | rezumare, reformulare, titluri și politețe |
| Extracție și clasificare | extragerea câmpurilor, sentiment, intenție și categorii |
| Explicații | definiții și diferențe între concepte |
| Productivitate | studiu, organizare, prioritizare și planuri simple |
| Viață cotidiană | bagaje, ordine, buget simplu, evenimente și planuri practice |
| Comunicare | mesaje profesionale și răspunsuri sociale scurte |
| Creativitate ușoară | titluri, sloganuri și formulări foarte scurte |
| Decizie | comparații între opțiuni numai pe baza datelor furnizate |
| Sinteză multi-constrângere | proiecte, feedback, planuri și situații cu dependențe |
