# ProofWriter V2020.12.3 acquisition and baseline

The official AI2 ProofWriter landing route currently redirects to the public S3 object recorded in `source-manifest.json`. The first resumable transfer through the redirect was rejected during acquisition because the redirect response was concatenated with a byte-range response. That invalid local object was removed before validation. The retained object was downloaded directly from the AI2-provided S3 endpoint, matches the recorded byte length and SHA-256 digest, and passes complete ZIP integrity validation.

The cache retains the complete immutable archive and the complete extracted tree. Resource budgets did not remove records. A deterministic streaming validator visited all 110 JSONL files, 702,271 records, and 2,670,022 task items without accumulating the corpus in memory. It parsed all source logical representations as inert data. The only source inconsistency found by the structural accounting pass is the `NRule` metadata mismatch on 124 CWA birds-and-electricity test records. Those records remain intact and are not part of the development score.

The baseline has two deliberately separate paths. The logical-form path compiles the official OWA representations into generic signed triples and safe Horn rules, then uses the unchanged ESLM closure implementation. Its exact three-way scorer compares a query literal and its polarity inverse against the derived closure. On 300 development-visible cases selected uniformly across five official depth variants and three answer classes, this path is correct in 300 cases and has a structurally valid support witness in all 300 cases. The result establishes only the named 300-of-50,844 development protocol. It is not a complete ProofWriter score, a hidden-test score, a CWA score, an abduction score, or a natural-language autonomy score.

The direct natural-language diagnostic submits the same selected development cases to the unchanged controlled-English runtime with Coding Agent disabled. All 300 end as `UNPARSED`, and the session compiler rejects 4,100 theory statements in aggregate. This establishes an early language-compilation gap rather than a Horn-deduction gap. The next generic improvement would need declared-predicate language compilation, signed facts and rules, and a three-valued query contract. It must generalize under renamed entities, predicates, clause order, polarity changes, distractors, and nonce vocabulary; no benchmark ID, source row, answer, or ProofWriter constant may enter core control flow.

The official archive does not bundle a dataset license. The supporting `allenai/ruletaker` repository is Apache-2.0, but this receipt does not infer that its software license automatically governs the separate dataset ZIP. The locally cached source is used for research validation without plaintext redistribution while archive-specific terms are clarified with AI2.
