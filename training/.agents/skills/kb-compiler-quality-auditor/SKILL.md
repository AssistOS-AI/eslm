# KB Compiler and Quality Auditor

## Canonical authority

Use this skill after canonical records exist. Verify deterministic IDs, namespaces, dependencies, schema conformance, declared terms, safe variables, qualifiers, provenance, time, contexts, confidence policies, alignments, retractions, and source coverage. Reject arbitrary code, undeclared operators, invalid bindings, missing lineage, timestamps as sole identity, or qualifiers hidden in predicate names.

Measure duplicate assertions, conflicting claims, unresolved alignments, unsupported predicates, missing lexemes, confidence distribution, provenance coverage, orphan terms, source and license mixtures, and scope collisions. Distinguish disagreement between sources or contexts from an internal contradiction.

## Compilation

Produce a small `manifest.json`, `shards.json`, and immutable JSON data segments. Build stable-to-local dictionaries, lexical access paths, assertion indexes, event-role indexes, rule-head and rule-dependency indexes, provenance segments, and conservative routing summaries only when the source and query profiles justify them.

Every shard declares identity, kind, access path, predicate or range coverage, record count, bytes, checksum, and dependencies. Corpus text cannot choose a path. The manifest permits registration and planning without loading all assertions. Approximate fingerprints may rank candidates but cannot exclude an exact dependency.

## Equivalence and resource tests

Run representative and adversarial queries against canonical and compiled forms. Run lazy routing and exhaustive routing under equivalent budgets. Compare semantic records, qualifiers, contexts, result statuses, proof premises, and provenance. Any false-negative routing, qualifier loss, source loss, nondeterminism, or stale index is a critical failure.

Profile read, validation, dictionaries, mapping, sharding, indexes, provenance, emission, registration, cold loading, positive query, negative query, deep proof, ambiguity, conflict, and overlay execution. Stop when memory follows the complete decoded source unexpectedly, one shard dominates without semantic reason, validation duplicates the graph, or a query loads unrelated domains.

## Publication

Publish canonical records, compiled package, manifest, source lineage, quality report, equivalence report, and build profile atomically. Do not mutate an existing published version. Updates are immutable overlays or new versions. Registration is separate from publication and deletion.
