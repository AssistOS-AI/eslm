CLUTRR: compositional kinship relations

CLUTRR tests whether a system can compose known family relations across a chain and infer the requested relation between two people, including chain lengths that stress systematic relational composition.

What enters the current symbolic method

The current probe uses validated structured evidence from the source: typed story edges, edge types, gender metadata, node mapping, and the ordered query endpoints. It does not claim unrestricted extraction of those relations from every narrative rendering. The clutrr-kinship-algebra package declares relation classes, inverses, endpoint refinements, and compositions. Trusted generic code applies that algebra to the graph.

Current ESLM protocol

The development sample contains 108 cases, with 12 cases at every relation-chain depth from 2 through 10. Those 108 were selected from 1,146 validated structured rows in the listed source files. The expected label stays outside the reasoning input. A returned relation earns a point only when it equals the host-side label. The run is development-visible because sampled evaluation rows and their aggregate failures informed implementation.

What AMBIGUOUS means

AMBIGUOUS means the available symbolic evidence licenses more than one output label and provides no invariant basis for choosing one. It is not the same as UNKNOWN: the graph supports a constrained set of kinship results, but cannot distinguish members of that set. Forced-label benchmark scoring counts the abstention as a failure even though preserving ambiguity is safer than guessing.

The observed ambiguity is unusually strong. Some projected graphs are isomorphic after renaming every person while preserving edge types, genders, and query order, yet the official labels differ between a direct and an in-law relation. A deterministic method invariant under entity renaming must return the same output for the same typed structure, so it cannot match all conflicting labels without additional observable evidence. The exact proof and its scope are documented on the exceptions and issues page.

Scope of the result

The score supports typed graph composition across the sampled depths. It does not establish arbitrary kinship prose parsing, and it does not authorize resolving the four ambiguous cases from person names, row identifiers, answer frequency, or candidate order. A future protocol may add source evidence that distinguishes the labels; until then the honest result retains the ambiguity.
