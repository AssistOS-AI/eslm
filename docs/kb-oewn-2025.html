Open English WordNet 2025

oewn-2025 is a source-derived lexical KB compiled from the complete official 2025 JSON archive. It keeps distinct word senses instead of forcing a surface word into one global entity. The runtime can define a lemma, count its senses, list synonyms across senses and search a bounded hypernym path.

What was compiled

InventoryCountMeaning in ESLM
Synsets107,519Sense-compatible groups with part of speech, members, definitions, examples and selected taxonomic links.
Unique normalized lemmas127,311Surface lookup keys that point to one or more synsets; ambiguity is retained.
Member occurrences185,129Lemma membership across synsets, including polysemous words such as dog and bank.
Definitions and examples107,524 / 49,596Text returned as source evidence; it is not silently converted into universal rules.
Generated code38 modules, 23,771,871 bytes10 numeric synset shards, 27 lemma shards and one static manifest.

Run it

node src/cli.mjs ask "Define dog" --kb oewn-2025
node src/cli.mjs ask "What are synonyms of dog?" --kb oewn-2025
node src/cli.mjs ask "How many senses does bank have?" --kb oewn-2025
node src/cli.mjs ask "Is a dog an animal?" --kb oewn-2025

The last query performs bounded graph traversal and reports the proof length. It does not claim that every sense of dog is an animal. A missing path returns open-world UNKNOWN, not a negative fact.

Build, validate and profile

node src/cli.mjs kb build oewn-2025
node src/cli.mjs kb validate oewn-2025
node scripts/test-source-kbs.mjs --cases 100

The official archive is cached at training/.cache/corpora/oewn-2025/ and excluded from version control. training/KBs/oewn-2025/source-manifest.json records the frozen artifact; build-report.json records counts and resources; generated executable code is under model/. The recorded full build took about 1.34 seconds and added about 281 MB RSS during compilation. Cold import took about 0.80 seconds and added about 349 MB RSS in an isolated measurement.

Known limits

The current query compiler does not perform contextual word-sense disambiguation; it searches the candidate set licensed by the lemma. It does not import the optional proper-noun Namenet extension, does not treat meronymy as universally transitive and does not interpret missing edges as false. The provider can assemble the complete manifest or load lemma/synset buckets through a bounded cache under an explicit memory target. Contextual sense choice, not shard residency, is now the main semantic limitation.
