# DS015 Experiment Roadmap, Ablations, and Falsification

## Core Content

### Research questions

RQ1 asks whether coding-agent synthesis can transform a finite corpus into executable modules that answer held-out paraphrases and compositions better than literal retrieval. RQ2 asks how model source size, synthesis cost, and runtime efficiency scale with evidence. RQ3 asks where explicit rules and state execution outperform or underperform current LLM references. RQ4 asks whether linguistic constructions transfer across domains. RQ5 asks whether traces and abstention are correct, not merely available.

### Stage A: infrastructure and honest vertical slice

The current stage establishes Node-only structure, model contract, synthesis skill, interactive and batch CLI, deterministic rules, provenance, internal evaluation, neutral benchmark protocol, result HTML, and detailed specifications.

Exit requires all checks passing, zero Python files outside preserved source material, operation from root and training directory, explicit unsupported behavior, and documentation that labels smoke scores honestly.

### Architecture gate before real-corpus training

DS019 is the next blocking stage. It requires stratified source probes, profiling across training and queries, streaming readers, compact dictionaries and shards, query-directed retrieval, sense ambiguity, and explicit temporal, spatial, domain, fictional-world, perspective, and hypothetical scope. No large corpus may be ingested while peak memory scales with the complete source, session facts trigger full-model closure, or profiling cannot attribute hotspots.

The gate first uses synthetic scale cases and a WordNet probe. It then compares model representations by generated bytes, cold import, RSS and heap, index build, median and p95 query latency, postings examined, rules activated, and proof fidelity. Passing a small correctness suite without these measurements is insufficient.

### K1: lexical knowledge core

Implement the Open English WordNet 2025 Node adapter, source manifest, probe report, sense-aware records, `core-senses` and `full-lexicon` profiles, relation indexes, and taxonomy queries. Measure exact inventories, rejected records, ambiguity, relation depth, unseen paraphrases, import and query cost, and source-held-out execution.

### K2: event and social commonsense

Compile ATOMIC 2020 into independently loadable `social-core` and `event-causality` profiles only after event templates, participant binding, perspectives, and hypothesis realization exist. Evaluate actor-role accuracy, relation direction, alternatives, and calibration. A typical continuation must never be realized as a categorical fact.

### K3: relation-specific commonsense

Implement filtered English ConceptNet profiles with relation-specific semantics, upstream-source attribution, WordNet overlap detection, defeasible properties and capabilities, explicit exceptions, and bounded causal hypotheses. Unsafe inheritance or duplicate-source support invalidates a build even if coverage rises.

### K4: bounded geography

Compile a GeoNames `countries-and-capitals` profile with alternate names, feature types, coordinates, and administrative containment. Measure identity resolution, relation-typed spatial composition, cold loading, query selection, and memory. A global-places profile is a separate later scale decision.

### K5: optional thematic Wikidata

Wikidata is not a near-term milestone. A later experiment may build a bounded dated `science-core`, `geography-crosscheck`, or `history-core` pack only when it has a concrete need, fixed seeds and properties, qualifier support, and measurable value beyond the preceding KBs. The complete dump is never a generated profile target.

### Parallel diagnostic track: grounded micro-world QA

Implement bAbI statement/event compilers, indexed query-directed inference, explicit negation/indefinite knowledge where required, counts/lists, coreference, temporal order, and path constraints. Train/generated modules may contain lexical constructions and general rules but not held-out stories.

Measure per-task accuracy, parse coverage, conditional reasoning, support trace, chain depth, distractors, entity substitution, latency, and model size. Compare against published baselines and raw predictions from current LLMs under identical contexts.

Falsification: if correct symbolic rules and parsed premises still fail compositional depth, the executor/index design is wrong. If parsing dominates failures and constructions grow per example, the compact language hypothesis is weak.

### Parallel diagnostic track: relation composition

Add CLUTRR kinship ontology, relation algebra, mention resolution, and noise handling. Hold out chain lengths and selected language templates. Compare explicit composition with LLM predictions.

Ablate generated language constructions, relation rules, alias indexes, and query-directed planning. Test whether rule source, depth, and proof are correct. Stop expanding kinship facts if the system is memorizing pairs rather than composing relations.

### Parallel diagnostic track: entity and event state

Implement event/state epochs and run Entity Tracking plus controlled extensions. Vary sequence length, paraphrase, operation order, irrelevant operations, invalid actions, and coreference. Compare final answer and exact transition trace.

This stage must demonstrate correct state transitions under varied English constructions, unseen entities, distractors, and longer operation sequences before making a general state-tracking claim.

### Parallel diagnostic track: grammar

Expand typed constructions and morphology for selected BLiMP phenomena, with phenomenon-specific diagnostic traces. EWoK, SimpleQA, and other knowledge suites must state overlap with loaded corpora and separate missing evidence, language compilation, and reasoning failures.

Do not tune to public test labels. Use official training/development resources or generated contrastive examples with disjoint templates.

### Later stage: narrative and text evidence

Implement StoryIR, stateful event parsing, discourse, schema modules, ending verification, and eventually controlled generation. Evaluate controlled story corpora and Story Cloze. Compare a total surface scorer, structured diagnostic reranking, and only later a proven normalized structured model.

Falsification: remaining near chance after adequate parse/world coverage weakens narrative schema/scoring hypotheses. Strong template-only performance with poor paraphrase confirms compilation failure rather than reasoning success.

### Cross-stage ablations

Remove typo repair, generated constructions, alias index, rule engine, provenance verification, discourse state, narrative schema, and abstention thresholds individually. Replace generated modular code with literal nearest-record retrieval. Compare full closure with query-directed execution. Compare one large generated module with semantic shards. Compare multiple coding-agent synthesis runs.

Each ablation declares which causal hypothesis it tests. An ablation that changes several components at once is exploratory, not explanatory.

### Budgets and stop rules

Set packet size, synthesis agent calls/tokens/time, generated source bytes, maximum rules/constructions, validation iterations, and benchmark queries before a run. Stop an iteration when budget is exhausted, hidden data would be required, validation cannot establish safety, or improvements depend on case-by-case answer branches.

### Artifact record

Every experiment archives configuration, packet/source hashes, candidate digest, agent transcript reference, model manifest, validation report, predictions, scorer version, results, environment, and interpretation. Latest HTML is a convenience view; immutable experiment records will live under versioned training work storage or external artifact storage.

## Decisions & Questions

### Q1. What is the next implementation priority after v0.1?

Response: Complete WordNet and ATOMIC source builds and budget-aware query-selected providers exist. Their next semantic gates are contextual sense selection, participant binding, calibrated ranking, compact indexes, and held-out source-aware evaluation. Filtered ConceptNet and bounded GeoNames require independent probes and streaming adapters before any learning cycle. Wikidata remains optional and thematic. bAbI, CLUTRR, Entity Tracking, and BLiMP remain controlled diagnostics rather than persistent world knowledge.

### Q2. When is the experiment allowed to change the eight operators?

Response: Only after repeated annotated circuits cannot be represented without operational loss and alternatives such as a new type, mode, executor, or macro have failed.

### Q3. What result would justify stopping the project?

Response: Persistent one-example-per-code growth, leakage-dependent performance, poor paraphrase transfer, and no advantage in verification/replay/efficiency over external systems would jointly undermine the approach.
