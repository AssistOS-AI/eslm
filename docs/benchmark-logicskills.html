LogicSkills: symbolization, validity, and finite countermodels

LogicSkills is not one accuracy task with three differently formatted answers. It tests three connected semantic obligations: compile controlled language into first-order formulas, determine whether a conclusion follows from premises, and construct a finite structure that witnesses invalidity. ESLM preserves those output contracts separately because a string match cannot establish logical equivalence or validate a countermodel.

Current measurements: Read the generated LogicSkills rows on the evaluation dashboard or inspect the raw v2 report. Development and fresh subtracks remain separate there.

Source and lifecycle

The primary source is Rabern, Mondorf, and Plank, LogicSkills: A Structured Benchmark for Formal Reasoning in Large Language Models, together with the official author repository. ESLM freezes the author revision recorded on the sources page, retains the complete archive, and streams every row of the normalized 1,500-case export. The benchmark question and JSON data are CC BY 4.0; repository code is MIT.

The release is a fixed public evaluation set rather than a training corpus. A label-blind partition is stratified by task and language. Development consumers see the task, language, input, identifier, and output contract but never the reference formula or validity index. Each fresh subtrack has an independent open-or-sealed lifecycle, so evaluating countermodels cannot silently expose symbolization or validity labels. The generated report records which subtracks ran and whether their frozen receipts remain current.

Symbolization is semantic compilation

A symbolization answer is correct when it denotes the same class of structures as the intended formula, not when its concrete variable names or parenthesization match. Alpha-renaming bound variables, reordering conjunctions, replacing an implication by an equivalent disjunction, or choosing another harmless surface normal form must not change the verdict. Conversely, reversing a binary predicate, moving a negation across a quantifier, changing existential to universal force, or widening a pronoun's antecedent must fail even when most tokens remain identical.

The required intermediate representation therefore needs typed variables, predicate arity, quantifiers and their scopes, connectives, equality policy, and source-span provenance. A source adapter may decode the official record shape, but reusable composition of quantification, polarity, anaphora, relative clauses, and argument order belongs in the generic language layer. Background theory is standard first-order logic, while the benchmark's exact accepted fragment and evaluation policy come from its paper and frozen release.

Validity requires both proofs and countermodels

For premises Γ and conclusion φ, validity means that every interpretation satisfying Γ also satisfies φ. A correct positive result must carry a derivation, an exhaustive finite certificate under a declared finite-model theorem, or another independently checkable witness. A correct negative result must supply a structure M with M ⊨ Γ and M ⊭ φ. Merely failing to find a proof is not evidence of invalidity.

The finite-countermodel verifier must validate a bounded domain, total interpretations for every predicate used by the formulas, variable assignments, and recursive formula truth. It then checks every premise and the negated conclusion independently of the constructor. Isomorphic structures are equivalent evidence: domain element names and serialization order cannot affect correctness. This is closely related to the model-theoretic use of a countermodel and to finite-model finding, but ESLM must publish the exact fragment for which its search is complete.

Carroll language and nonce transfer

The Carrollian subset deliberately exposes whether the system learned logical constructions rather than memorized ordinary-world associations. Predicates and entities may be semantically empty or unfamiliar while determiners, negation, relation direction, and quantifier scope still carry formal meaning. Metamorphic tests therefore rename every open-class symbol, permute premise order, alpha-rename bound variables, and compare each valid item with a one-operator semantic contrast.

How to interpret the separate rows

The controlled symbolization route uses a source-provided lexicon only to map declared open-class symbols; generic grammar code composes quantifiers, negation, conjunction, disjunction, conditionals, biconditionals, and argument order into typed FOL. Each output carries a derivation that replays from token spans and construction rules. The host opens the isolated reference formula only for scoring and applies a sound, deliberately incomplete equivalence checker. Unsupported input is an abstention, while an emitted non-equivalent formula is a mismatch. Adapter state and promotion status come from the generated row.

The finite-countermodel route parses the formal argument into a typed AST, searches constant interpretations over the declared finite domain, grounds quantifiers, uses generic SAT search, and accepts the decoded structure only after an independent evaluator establishes that every premise is true and the conclusion false.

NO_APPLICABLE_METHOD on an unsupported symbolization or a validity case means the adapter constructed and validated the requested task contract but no authorized method can produce that output. It is not a wrong formula, an invalid answer, an absent data file, or a Language Agent failure. The dashboard separates development symbolization, development countermodels, and the previously frozen fresh countermodel subtrack; it does not invent one official aggregate percentage across unlike output contracts.

Promotion criteria

A candidate is eligible only when nonce and full-renaming tests pass; formula equivalence accepts harmless syntactic variants and rejects meaning changes; every positive answer has an independently checked witness; every negative answer has a verified countermodel; premise and candidate ordering do not alter semantics; development membership alone guided changes; the Language Agent invocation count remains zero; and the behavior, scorer, source, partition, and tests are frozen before one aggregate-only fresh execution.
