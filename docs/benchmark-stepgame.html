StepGame: multi-hop spatial constraints from controlled text

StepGame tests whether a chain of qualitative spatial statements determines the relation between two entities. ESLM separates source-template recognition from reasoning: the adapter emits typed vector facts, while a benchmark-neutral constraint solver composes them and returns a replayable displacement path.

Current measurements: Read the generated StepGame rows on the evaluation dashboard or inspect the raw v2 report. Validation outcomes and status counts remain generated.

The label is joined only after the vector result exists. Relation words and templates never enter generic core control flow.

Source and denominator

ESLM pins the corrected March 2024 official dataset release and the official generator repository separately. The source contains 155,000 rows: 50,000 training, 5,000 validation, and 100,000 test. Every JSONL row is streamed and retained; no case is rejected by file size. An execution row states which split and hop depths ran; source inventory alone is not an execution denominator.

Vector semantics

A declarative system assigns every accepted relation an integer displacement vector. A fact relating subject s to object o means p(s)−p(o)=v. The executor anchors one query endpoint, propagates coordinates through asserted and inverse edges, rejects inconsistent cycles, and classifies the final vector by its declared component-wise sign. The core receives abstract relation and dimension identifiers, so complete renaming preserves the result.

The path witness lists every original or inverse edge in order and the exact accumulated vector. A verifier checks each edge against the input facts and recomputes the sum and output class. A disconnected query or incomplete accepted evidence remains UNKNOWN; the engine does not use the answer label or choose the most frequent direction.

How to read the result

A solved case must be exact and carry a verified path witness. UNKNOWN means the accepted evidence did not determine an answer; it is not a reversed guess. The frozen template inventory includes a generator function that omits one of the two entity placeholders and therefore cannot encode a binary relation. A case containing that pattern may still be solvable from independent facts, so the execution report must record actual statuses rather than assign a failure from pattern presence alone.

This is a source anomaly and an engineering boundary, not permission to reconstruct the missing entity from the answer. A repair requires independent source evidence or a corrected official release. The page does not claim a universal impossibility for spatial reasoning, and the unopened test split is not used to tune the template policy.

Theory and citation

The exact method is a graph of additive difference constraints and potential assignments, described technically in the state, time, and relations chapter. The source citation is Zhengxiang Shi, Qiang Zhang, and Aldo Lipani, StepGame: A New Benchmark for Robust Multi-Hop Spatial Reasoning in Texts, AAAI 2022.
