ESLM Documentation / Training

Training means generating and improving executable symbolic code

ESLM does not optimize tensors. A coding agent studies authorized training evidence, designs semantic representations and executable mechanisms, and writes or revises Node.js compilers and model modules. Deterministic Node code then processes the complete source. Candidates are accepted only after validation, fresh tests, proof checks and regression gates.

This layout keeps four things separate: download cache, knowledge sources, evaluation datasets and the promoted core. A public archive is not executable knowledge until its compiler, model, report and validation exist. A benchmark dataset is not a KB merely because the project can download it.

Two repository-owned agent skills

Source synthesis

training/.agents/skills/synthesize-eslm-model/ defines train-only evidence access, large-corpus probing, semantic mapping, modular ESM output, provenance, validation and promotion boundaries. A coding agent may design schemas, mappings, rules, query forms, sharding and validators. It may not inspect hidden evaluation, encode test answers or promote its own candidate.

Benchmark-guided symbolic learning

training/.agents/skills/benchmark-guided-symbolic-learning/ defines the iterative competence loop requested for later datasets. It requires an accepted checkpoint, capability map, baseline, four evaluation pools, trace-based failure clusters, an explicit KB/core decision, structurally varied and metamorphic tests, regressions, fresh samples and a research note. Its two self-contained Node utilities initialize a learning cycle and compare normalized baseline/candidate reports.

node training/.agents/skills/benchmark-guided-symbolic-learning/scripts/init-learning-cycle.mjs \
  --output training/work/cycles/example-001 \
  --dataset DATASET_ID \
  --checkpoint ACCEPTED_ID \
  --hypothesis "reusable hypothesis" \
  --classification kb \
  --cluster lexical-mapping \
  --working WORKING.jsonl \
  --regression REGRESSION.jsonl \
  --fresh FRESH.jsonl

node training/.agents/skills/benchmark-guided-symbolic-learning/scripts/compare-learning-cycle.mjs \
  BASELINE.json CANDIDATE.json COMPARISON.json

What the coding agent learns versus what the compiler does

Coding-agent responsibilityDeterministic Node responsibility
Inspect a stratified authorized sample, field inventory, anomalies and counterexamples.Read every authorized source record with a reproducible adapter.
Decide whether source relations are exact, defeasible, lexical, temporal, scoped, conflicting or unsupported.Apply the frozen mapping to every record, preserving rejection and repair counts.
Design types, event frames, aliases, rules, profile boundaries, shard keys, query contracts and validation probes.Normalize, deduplicate, group, index, emit ESM, write manifests and measure resources.
Cluster benchmark failures and decide whether the reusable correction belongs in a KB or generic core.Run fixed focused, fresh, metamorphic, regression, proof and performance evaluators.
Explain why a candidate should be accepted.Produce comparison evidence; never auto-promote solely from aggregate accuracy.

Build and verification commands

npm run test:kbs:random
npm run benchmark:conversation
npm test
npm run docs:check

Build reports include source and generated byte counts, accepted/repaired/rejected records, throughput, elapsed time, RSS and heap deltas. Runtime random tests record seed, exact dataset inventories, pass/fail outcomes and slowest cases. Generated source KBs are explicitly non-benchmark-eligible because their test questions sample exposed knowledge.

Scale boundary before another source

The WordNet and ATOMIC models support complete eager import and budget-aware shard access over the same generated code. The eager combined source-KB random run uses roughly 0.6 GB additional RSS; the exact value remains in its report. --memory-mb activates adaptive residency and --memory-policy lazy forces the bounded path for diagnostics. Before ConceptNet or GeoNames, the source side must still stream compilation, emit compact relation-aware indexes, and pass a benchmark-guided learning cycle without regressions.
