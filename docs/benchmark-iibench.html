IIBench: immediate inference over categorical propositions

IIBench isolates classical operations that are easy to hide inside broader benchmarks: the A/E/I/O proposition forms, opposition judgments, conversion, obversion, contraposition, and categorical syllogisms. ESLM maps supported operations to one vocabulary-independent categorical method.

Current measurements: Read the generated IIBench rows on the evaluation dashboard or inspect the raw v2 report. Scores and fresh-checkpoint state do not live on this page.

What the protocol measures

Opposition cases ask which truth relations follow between universal and particular affirmative and negative statements. Transformation cases ask for a proposition produced by a named validity-preserving operation. Syllogism cases require two-premise categorical composition. The source uses several surface realizations, so scoring must distinguish logical equivalence from exact string identity.

How to read the outcomes

The opposition track compares True, False, and Undetermined. Immediate transformations require the declared result form after complement-parity normalization. Syllogisms accept reversible obversion, simple conversion, and valid contraposition equivalents. The score shown on the dashboard is gold-equivalence accuracy, while the execution receipt separately validates whether every returned syllogism conclusion is actually entailed.

Partition and license boundary

The author release is frozen and every row was schema-validated. A label-blind partition exposes development members and seals the remainder. The pinned repository has no explicit benchmark LICENSE; local MIT-project research evaluation is recorded without claiming that upstream Wikidata or WordNet licenses automatically license the assembled benchmark. Redistribution requires clarification from the authors.

Implemented method and protocol ambiguity

The generic method is explained in Categorical logic. It validates typed terms, preserves transformation-specific existential commitments, enumerates the complete bounded population space, emits a model witness, and never receives source identifiers or gold forms. A strict syllogism scorer can still face an A-versus-I or E-versus-O gold-selection ambiguity: both conclusions may be entailed even when the prompt does not declare which strength it requests. See the structural proof. The generated rows report gold-equivalence and witness validity without turning that ambiguity into a hidden tie break.
