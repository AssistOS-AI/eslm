ESLM Documentation / Implementation status

Implemented Stage A boundary and the work that remains explicitly open

The repository has completed the structural reset from executable generated knowledge modules to a trusted generic runtime plus declarative KB packages. This page separates working behavior from architectural commitments that are specified but not yet implemented.

Implemented now

The runtime supports deterministic normalization and a controlled English subset, session facts and rules, explicit query objects, task frames, a capability registry, plan records, direct retrieval, safe Horn deduction, structured results, provenance, and structured unsupported-language or unresolved-goal behavior. State-bearing language now includes bounded movement and possession transitions, a predecessor query over recorded location history, and property questions that can request configured induction. The Entity Tracking integration enters through a reviewed masked-container task adapter and executes an allowlisted, bounded container-transition method; this is a structured task route rather than a claim that arbitrary masked prose is handled by the ordinary question parser.

The CLI exposes interactive, one-shot, batch, KB administration, training Coding Agent dry-run or execution, evaluation, public benchmark status and probes, and documentation operations. Its operator question profile enables a distinct Language Agent wrapper by default, while the deployable EslmRuntime remains offline and does not import that wrapper. The CLI still runs the direct symbolic runtime first; only UNPARSED input can reach an external Language Agent, each proposal must pass host anchor checks, and accepted CNL is reparsed by the same symbolic runtime. An episode is limited to three proposals and feedback contains no answer, KB result, or proof. --no-external-language-agent and interactive /normalize off select the entirely offline profile. Canonical evaluation, benchmark, public-probe, and regression commands use that explicit offline option. The current adapter invokes Codex; a local receipt for gpt-5.3-codex-spark proves only that one installed Codex CLI accepted that configuration.

The KB toolchain validates canonical record types and cross-record references, rejects unsafe rules, compiles stable JSON shards and manifests, checks hashes, opens allowlisted paths, and projects canonical data into reasoning indexes. Eight repository-managed packages are currently available. quick exercises the generic fact-and-rule path; babi-v1.2-language carries only source-visible property vocabulary and induction policy; clutrr-kinship-algebra carries typed relation policy; Open English WordNet and ATOMIC supply lexical and defeasible event evidence; GeoNames supplies country and populated-place facts; ConceptNet supplies reviewed English relation edges; and World Relations supplies semantic compatibility constructions and implications. None is benchmark-eligible merely because it can be loaded.

Training has four self-contained skills and an isolated subprocess runner. Prepared legacy datasets, old candidates, transient work, the global generated model, and executable KB payloads have been removed. A training run now begins from an explicit train-visible packet, a namespace, and a hashed Stage A baseline analysis, and ends with an untrusted declarative candidate and receipt. The portable skill validator and trusted host compiler enforce the same field and reference contract. Candidate validation, compilation, package audit, and registration are distinct implemented operations. Promotion remains a distinct required gate but has no CLI command yet, so no candidate can become a published package merely by completing the currently implemented sequence.

Partially implemented

Contexts exist in records and result structures, but full branching world models, general temporal projection, speaker commitments, and mature contradiction policies remain incomplete. Temporal support answers one predecessor form from a bounded session history; it does not implement interval logic or unrestricted event ordering. Typed relation algebra composes validated graphs but does not yet parse unrestricted kinship prose. Semantic compatibility recognizes a reviewed construction inventory and returns signed evidence, not calibrated language probability. Narrative continuation ranks bounded event frames defeasibly and does not generate or fully understand stories. Factoid routing distinguishes understood questions from missing evidence, but the public KB collection remains far from encyclopedic coverage. Resource plans and shard caches are exercised for public KBs, while operating-system hard memory enforcement is not claimed.

The public benchmark adapters now freeze and validate cached sources, isolate host-only oracles, stratify probes, and preserve task semantics. Their published report is deliberately a development and diagnostic artifact. It records no Language Agent calls; normalizationCandidateRate means the fraction whose direct result was UNPARSED and therefore could trigger the optional profile. It does not mean an agent was invoked, and it does not count wrong-but-parsed cases.

Finite reasoning now includes a function-free first-order countermodel method for a declared finite domain. It enumerates constant interpretations, grounds quantifiers, delegates the Boolean search to verified DPLL, decodes total predicate extensions, and independently re-evaluates every original premise and the conclusion. A returned model is sound evidence of invalidity; failure to find one in the declared domain is not promoted to unrestricted validity.

The benchmark research catalog additionally registers sixteen requested families across a seven-stage queue. All sixteen have validated adapters and execution receipts. Their typed task-adapter results remain separate from direct natural-language coverage and from official leaderboard claims. LogicSkills reports conservative development symbolization, verified development and fresh countermodel subtracks, and unavailable validity separately rather than inventing one aggregate. SLR-Bench, Defeasible NLI, αNLI / ART, ReClor, and LogiQA report complete task coverage or visible unavailable scope rather than misleading 0% scores. ProverQA and SATBench have fresh source-annotation tracks; neither is a direct-language score. ZebraLogic reports public-clue satisfaction and uniqueness rather than private-label accuracy. Spatial development results have verified qualitative proof trees, vector paths, or inequality witnesses and an explicit StepGame/SpaRP overlap audit. The status command links every official source and remaining action; a cache alone never advances a state until revision, hashes, schema, split boundaries, rights, and oracle isolation are recorded.

The interactive regression corpus is a separate evidence layer. It generates 4,096 deterministic nonce cases from 26 templates in twelve implemented or deliberately unknown structural groups. Its provenance tags currently connect eleven benchmark families to the constructions they inspired, and every case passes through the direct runtime without Language Agent assistance. This protects previously implemented constructions from regressions; it is not public benchmark data and cannot replace any source-specific probe.

Not yet claimed

The project does not currently claim unrestricted English understanding, learned construction grammar, general temporal or modal reasoning, complete defeasible logic, unconstrained narrative generation, calibrated probabilistic language scoring, complete performance on any of the seven public benchmark families, encyclopedic factual coverage, or parity with broad neural language models. A locally successful Codex CLI receipt proves only that one installed client accepted one exact slug in one operator configuration. A cache hit proves that previously generated normalized text passed the current cache and anchor checks; it is still agent-derived language and never becomes direct-symbolic evidence.

Acceptance path from here

The next implementation work deepens language constructions and discourse while keeping parser failures explicit; extends relation extraction beyond CLUTRR's structured graph evidence; expands independently sourced factual coverage rather than copying SimpleQA answers; broadens the reviewed world ontology and generic semantic frames rather than copying EWoK preferences; improves narrative state, event roles, and provider evidence rather than memorizing Story Cloze endings; tests narrow mechanisms on frozen fresh and renamed worlds; and repeats benchmark-guided cycles using development-visible evidence only. EWoK has an accepted, verified protected cache and an executable compatibility diagnostic; its rows remain uncommitted and never enter core dispatch or KB packages. Story Cloze has validated Winter 2018 caches, a label-isolating adapter, and a bounded defeasible prediction method; the delivered label-free test set still requires external official evaluation. Each step must preserve the security boundary, deterministic package behavior, negative controls, and core-versus-KB separation.
