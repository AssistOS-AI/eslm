Installed knowledge bases and their boundaries

A KB is an independently selectable executable evidence module. The CLI distinguishes ready from loaded: a generated model can be installed on disk without participating in the current answer. Every response identifies the active KBs, and any selected KB makes a clean public benchmark run non-comparable unless the protocol explicitly declares the exposure.

Inspect and change the active set

node src/cli.mjs kb list
node src/cli.mjs kb show quick
node src/cli.mjs kb show oewn-2025
node src/cli.mjs kb show atomic-2020

# one-shot execution is explicit
node src/cli.mjs ask "Define dog" --kb oewn-2025
node src/cli.mjs ask "Why might apologize?" --kb atomic-2020
node src/cli.mjs ask "Jhon is a man. Is Jhon going to die?" --kb quick

Interactive chat starts with all three top-level modules. Inside it, use /kbs, /load, /unload, and /model. One-shot, batch, evaluation, and benchmark commands load no optional KB unless --kb is present, preventing an evaluation from silently acquiring source knowledge.

Rebuild and validate

node src/cli.mjs kb build quick
node src/cli.mjs kb build oewn-2025
node src/cli.mjs kb build atomic-2020
node src/cli.mjs kb validate all
npm run test:kbs:random

QUICK build compiles reviewed JSON to the v1 graph contract. WordNet build parses every synset file and emits lemma/synset shards. ATOMIC build streams every train row and emits event shards. Validation imports generated data, verifies inventory and runs semantic smoke proofs. The seeded random suite then runs 700 source-backed queries across seven capability families.

Cost and next boundary

Both public KBs are modest on disk—about 23.77 MB generated WordNet code and 32.96 MB generated ATOMIC code—but JavaScript objects expand in memory. Their combined eager random run uses roughly 0.6 GB additional RSS. Static manifests remain the fast complete path; an explicit memory target selects bounded shard caches over the same generated envelopes. Larger sources additionally require streaming compilation, compact indexes, scoped semantics, and measured regression gates.
