BLiMP: grammatical minimal-pair preference

BLiMP tests whether an acceptability method ranks a grammatical English sentence above a minimally different ungrammatical sentence. It isolates grammatical contrasts; it does not ask for factual knowledge, free-form generation, or a percentage estimate of how much English the system understands.

What the benchmark forces the system to represent

Each pair changes a controlled grammatical property while attempting to keep vocabulary and meaning as close as possible. The 67 paradigms cover agreement, argument structure, binding, control and raising, determiner-noun agreement, ellipsis, filler-gap dependencies, islands, irregular forms, quantifiers, and subject-verb agreement. A useful symbolic account must model the relevant phrase structure and dependencies. A table keyed by paradigm name would not establish the capability, because it would not explain a renamed or newly constructed pair.

Current ESLM protocol

The adapter supplies both sentences without exposing the label to the scorer. The feature grammar assigns each sentence a deterministic scalar acceptability score. The evaluator then performs one strict comparison. It awards one point only when the grammatical member has the higher score. The report's current source contains 67,000 pairs. The latest published fresh run scored 13,400 pairs selected before the candidate was frozen; the separate 53,600-pair development partition had already been available for implementation work.

This is a direct symbolic preference protocol. No Language Agent normalization is used in the published run. Because BLiMP has no official train/test division, the documentation identifies which inspected rows are development evidence and which label-blind partition was retained for the one-time fresh checkpoint.

Correct, reversed, tied, and “ties fail”

Correct means the grammatical sentence received a strictly higher score. Reversed means the scorer expressed a preference, but assigned the higher score to the ungrammatical sentence. Tied means both sentences received exactly the same score, so the method did not distinguish the intended contrast. Ties fail means a tie earns no point: the benchmark asks for a preference, and abstaining is not counted as a correct forced choice. Reporting all three counts matters because the same overall accuracy can describe very different failure modes when one run contains many ties and another contains confident reversals.

What the percentage does and does not establish

The denominator is sentence pairs, not sentences, vocabulary items, English constructions, or user questions. A fresh score supports generalization across the represented paradigms under this feature scorer. It does not prove complete syntax, semantic interpretation, discourse understanding, or calibrated linguistic probability. Remaining failures should be repaired through reusable phrase structure, attachment, valency, agreement, and binding mechanisms, with nonce and contrastive controls—not through sentence fragments, paradigm identifiers, or expected labels copied into core code.
