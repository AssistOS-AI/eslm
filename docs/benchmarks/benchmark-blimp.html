BLiMP: grammatical minimal-pair preference

BLiMP tests whether an acceptability method ranks a grammatical English sentence above a minimally different ungrammatical sentence. Its focused scope isolates grammatical contrasts from factual knowledge and free-form generation, producing a precise minimal-pair measurement rather than a general estimate of English coverage.

Current measurements: Read the generated BLiMP row on the evaluation dashboard or inspect the raw v2 report. Execution counts, scores, and receipt currentness are intentionally not copied here.

Both members of the pair pass through the same feature grammar. Only their resulting score order determines the outcome; the benchmark label never enters the grammar.

What the benchmark forces the system to represent

Each pair changes a controlled grammatical property while attempting to keep vocabulary and meaning as close as possible. The 67 paradigms cover agreement, argument structure, binding, control and raising, determiner-noun agreement, ellipsis, filler-gap dependencies, islands, irregular forms, quantifiers, and subject-verb agreement. A useful symbolic account must model the relevant phrase structure and dependencies. A table keyed by paradigm name would not establish the capability, because it would not explain a renamed or newly constructed pair.

ESLM protocol

The frozen official source contains 67,000 labeled sentence pairs. The adapter supplies both sentences without exposing the label to the scorer. The feature grammar assigns each sentence a deterministic scalar acceptability score, and the evaluator awards one point only when the grammatical member has the higher score.

This is a direct symbolic preference protocol. Because BLiMP has no official train/test division, each execution receipt must identify its label-blind partition, development exposure, Language Agent policy, behavior digest, and checkpoint state. The dashboard shows whether an older one-shot receipt is still current rather than repeating its claim here.

Correct, reversed, tied, and “ties fail”

Correct means the grammatical sentence received a strictly higher score. Reversed means the scorer expressed a preference, but assigned the higher score to the ungrammatical sentence. Tied means both sentences received exactly the same score, so the method did not distinguish the intended contrast. Ties fail means a tie earns no point: the benchmark asks for a preference, and abstaining is not counted as a correct forced choice. Reporting all three counts matters because the same overall accuracy can describe very different failure modes when one run contains many ties and another contains confident reversals.

Evidence scope of a reported percentage

The denominator is sentence pairs, not sentences, vocabulary items, English constructions, or user questions. A score supports only the declared partition and feature scorer. It does not prove complete syntax, semantic interpretation, discourse understanding, or calibrated linguistic probability. Remaining failures should be repaired through reusable phrase structure, attachment, valency, agreement, and binding mechanisms, with nonce and contrastive controls—not through sentence fragments, paradigm identifiers, or expected labels copied into core code.
