Entity Tracking: executing container-state changes

Entity Tracking asks which objects remain in a queried container after a sequence of additions, removals, and moves. It tests persistent identity and state updates rather than factual recall.

Current measurements: Read the generated Entity Tracking row on the evaluation dashboard or inspect the raw v2 report. The selected sample and exact outcomes are generated evidence.

Add, remove, and move operations update one explicit state in order. The final query reads that state and returns an exact set rather than completing text by similarity.

Representation and execution

The reviewed adapter projects each bounded story into allowlisted operations. The generic state-transition method applies those operations in order and records the resulting container contents. This representation lets tests rename every object and container, insert irrelevant operations, reverse a movement, or query a different container without adding source vocabulary to the state engine.

ESLM protocol

A development probe selects cases deterministically across operation counts so it does not contain only the shortest stories. The scorer compares the final unordered contents required by the masked span: every required entity must appear and no extra entity may be returned.

A structured-case score does not mean that every available development row ran, that another split ran, or that unrestricted event prose can always be converted into operations. The generated row keeps tested-versus-available scope beside the numerator, denominator, input route, and execution receipt.

Outcome diagnosis

A wrong set indicates an operation, ordering, binding, or output-projection error. UNPARSED indicates that the adapter could not construct the declared operation sequence. UNKNOWN indicates that the sequence was understood but lacked the state needed for a determinate answer. Any development sample must be accompanied by nonce objects, changed operation order, removal controls, and queries whose correct result is empty.
