Story Cloze: selecting a coherent story ending

Story Cloze presents a four-sentence story and two possible fifth sentences. The task is to choose the ending that is more coherent with the participants, events, goals, causes, social expectations, and state changes established by the story.

Current measurements: Read the generated Story Cloze row on the evaluation dashboard or inspect the raw v2 report. Partition scope, omissions, accuracy, and currentness remain generated evidence.

The ranker builds bounded narrative state from the story and scores both endings under the same evidence policy. It selects one only when the declared margin is met.

Narrative method

The adapter supplies both candidate endings without their label. ESLM compiles the context into bounded participant and event frames, evaluates lexical bridges, polarity, tense, goals, causal consequences, social effects, and state compatibility, and asks ATOMIC, ConceptNet, and World Relations for typed evidence. The resulting rank is defeasible: it expresses which candidate has stronger current support rather than converting a plausible event into a universal fact.

ESLM protocol

The delivered validation artifact contains 1,571 labeled cases. A label-blind digest partition separates development-visible and reserved membership; the partition receipt and generated row own exact membership and execution scope. A correct case requires the selected candidate identifier to match the host-isolated validation label.

The delivered official test artifact contains 1,571 cases but no answer column. ESLM can produce predictions for it, but cannot compute a local correctness percentage without the external official evaluator. That is an unavailable local oracle, not a zero score and not a claim that the cases are impossible.

What an omission means

An omission is a case in which the ranker does not obtain the required margin between the two candidates and returns UNKNOWN instead of forcing a choice. The omission is counted as a failure in binary forced-choice accuracy. It remains separately visible because abstaining when evidence is balanced is a different engineering failure from confidently choosing the wrong ending.

Coverage boundary and next evidence

Likely failure families include incomplete modeling of goals, longer causal chains, social expectations, contradictions, and multi-event temporal dependencies; the generated diagnosis states which were actually observed. No result justifies copying an ending, story identifier, or candidate position into policy. Improvements must operate on event roles and relations, survive swapped-candidate and renamed-participant controls, and be measured on development evidence before a new untouched partition is opened.
