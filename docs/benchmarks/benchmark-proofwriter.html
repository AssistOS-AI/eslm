ProofWriter: open-world deduction with explicit support witnesses

ProofWriter provides natural-language theories together with inert logical representations. ESLM measures two layers independently: whether its Horn core solves the logical program, and whether its ordinary language frontend compiles the visible English into that program. Separate route labels preserve the evidence carried by each result.

Current measurements: Read the generated ProofWriter rows on the evaluation dashboard or inspect the raw v2 report. Sample size, logical score, and language coverage remain generated fields.

Under open-world semantics, absence of a query and its explicit opposite yields unknown. A witness names the source facts and rule applications.

What the protocol measures

An integrated development track samples the main open-world data across proof depths and all three answer classes. A query is true if its literal is in the independently computed closure, false if the polarity-inverted literal is in the closure, and unknown if neither is derivable. Both polarities yield an inconsistency rather than an arbitrary answer.

Why logical-form and language results stay separate

SOLVED LOGICAL FORM refers to the official inert representation passed through the generic Horn method. Natural-language coverage comes from a separate pass over the visible theory. Rejection of arbitrary predicates, explicit negative statements, or general rules is a frontend gap even when the supplied logical form is solved. Language Agent policy and actual invocation count are separate report fields; translation alone would not replace a missing generic rule-language compiler.

Scope boundaries

A report must state whether it includes closed-world variants, staged implication enumeration, single-fact abduction, NatLang variants, extended-depth variants, or official test files. Sampling affects evaluation cost only; the complete extracted source remains in the ignored cache and no valid row is deleted for size.

Source rights

The official archive contains no dataset-specific license file. The related RuleTaker software repository is Apache-2.0, but that software license is not silently applied to the archive.
