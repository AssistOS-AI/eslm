CLUTRR: compositional kinship relations

CLUTRR tests whether a system can compose known family relations across a chain and infer the requested relation between two people, including chain lengths that stress systematic relational composition.

Current measurements: Read the generated CLUTRR row on the evaluation dashboard or inspect the raw v2 report. The sample, score, failure totals, and replay metadata live there.

The current route starts from validated structured edges. The algebra composes those types for the ordered endpoints and preserves ambiguity when the graph does not identify one label.

What enters the symbolic method

The structured route uses validated source evidence: typed story edges, edge types, gender metadata, node mapping, and the ordered query endpoints. It does not claim unrestricted extraction of those relations from every narrative rendering. The clutrr-kinship-algebra package declares relation classes, inverses, endpoint refinements, and compositions. Trusted generic code applies that algebra to the graph.

ESLM protocol

A development probe must sample across declared relation-chain depths rather than select only short chains. The expected label stays outside the reasoning input, and a returned relation earns a point only when it equals the host-side label. The report records the selected and available counts, source files, split quality, execution route, and whether the sample was development-visible.

What AMBIGUOUS means

AMBIGUOUS means the available symbolic evidence licenses more than one output label and provides no invariant basis for choosing one. It is not the same as UNKNOWN: the graph supports a constrained set of kinship results, but cannot distinguish members of that set. Forced-label benchmark scoring counts the abstention as a failure even though preserving ambiguity is safer than guessing.

Some projected graphs are isomorphic after renaming every person while preserving edge types, genders, and query order, yet the official labels differ between a direct and an in-law relation. A deterministic method invariant under entity renaming must return the same output for the same typed structure, so it cannot match all conflicting labels without additional observable evidence. The exact proof and its scope are documented on the exceptions and issues page.

Scope of a result

A structured-route score supports typed graph composition across its declared depths. It does not establish arbitrary kinship prose parsing, and it does not authorize resolving ambiguous cases from person names, row identifiers, answer frequency, or candidate order. A future protocol may add source evidence that distinguishes the labels; until then the honest result retains the ambiguity.
