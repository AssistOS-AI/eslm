αNLI / ART: selecting an abductive narrative bridge

Abductive Natural Language Inference presents an earlier observation, a later observation, and two possible events that could connect them. The task is to select the more plausible bridge. Unlike deduction, several explanations may be logically consistent; the intended method needs defeasible causal, temporal, goal, state, and contradiction evidence.

Current measurements: Read the generated αNLI row on the evaluation dashboard or inspect the raw v2 report. This protocol page does not maintain execution counts, percentages, or checkpoint state.

Each candidate is evaluated as an intervening event sequence. Candidate order and the host-only answer label are never evidence.

Source and evaluation lifecycle

The pinned official ICLR 2020 archive contains 174,245 cases: 169,654 training, 1,532 development, and 3,059 official test cases. ESLM validates and retains every record and label in the six source files. Repeated training story identifiers, duplicate visible training pairs, identical candidate hypotheses, embedded line breaks, and replacement characters remain present and explicitly counted rather than becoming silent exclusions.

The visible adapter task contains the two observations and both candidate bridges. The preferred candidate is stored only in a host oracle and joined after a prediction exists. Development data may be used for research; the official test split remains outside the public loader. The generated report identifies which split, if any, was actually executed and whether its receipt still matches the current behavior.

What a symbolic bridge means

A future typed bridge contains one or more event frames with participant roles, temporal placement between the observations, polarity and modality, preconditions, effects, goals, and state transitions. KB providers may contribute provenance-bearing causal consequences, likely goals, social expectations, and contradictions. Evidence remains defeasible: a common consequence supports a bridge but does not become a universal theorem.

The ranker must score both candidates under the same declared feature and provider policy. A witness names the aligned participants, event and state links, supporting or conflicting records, feature contributions, final margin, and any unresolved dependency. A tie or insufficient margin returns an explicit unknown result. This is related to abductive reasoning, but the implementation must state its particular finite candidate and evidence semantics rather than claim unrestricted inference to the best explanation.

How to score inability on this forced-choice task

αNLI requires one of two candidate identifiers. If a non-empty evaluated pool receives no in-domain predictions, end-to-end accuracy and attempt coverage are both 0%, while selective accuracy is null because there are no attempted answers. A NO_APPLICABLE_METHOD result remains useful diagnosis, but it does not remove that case from the fixed denominator or turn inability into an unscored outcome.

A lexical overlap ranker, candidate-position preference, or source-specific phrase table would not satisfy the task. Core Guardian requires complete event and participant renaming, candidate permutation, irrelevant-detail controls, polarity and causal-direction contrasts, explicit evidence witnesses, and a meaningful negative case before a generic method can be registered. The existing Story Cloze continuation ranker is a bounded feature policy for a different task contract and is not silently reused as αNLI competence.

A standalone comparator can rank alternatives when it receives explicit, provenance-bearing causal, temporal, goal, state, contradiction, default, or participant evidence; it verifies the evidence digest, margin, and selected alternative independently. Any automatic event-frame projector remains a development experiment until it passes the genericity and witness gates. The generated row records whether such a subtrack ran and what it established.
