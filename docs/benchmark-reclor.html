ReClor: logical analysis of arguments in unrestricted passages

ReClor asks a reader to choose one of four answers after analyzing a short argument. The questions span entailment, assumptions, flaws, principles, strengthening, weakening, resolution, and parallel reasoning.

Current measurements: Read the generated ReClor row on the evaluation dashboard or inspect the raw v2 report. Method availability and execution totals are not maintained here.

Source boundary and zero-attempt scoring

The official v1 release contains 4,638 training, 500 validation, and 1,000 test records. Every train and validation record is retained and streamed through a closed schema. The preferred option is removed from the visible task and held by the evaluation host. The test file is retained in the ignored cache but was never parsed; only its byte length and digest were checked.

Every evaluated case requires one of four option identifiers. If a non-empty evaluated pool receives no in-domain predictions, end-to-end accuracy and attempt coverage are both 0%, while selective accuracy is null. NO_APPLICABLE_METHOD explains why a case was not attempted; it does not remove that case from the fixed denominator or imply that the system selected the opposite option.

Required generic method

A defensible method must compile propositions, quantifiers, conditionals, alternatives, causal claims, normative principles, speaker commitments, and discourse roles into an explicit argument graph. It must distinguish the question operator—entails, assumes, weakens, strengthens, explains, resolves, matches a flaw, or instantiates a principle—then evaluate every candidate using proofs, countermodels, or typed defeaters. Candidate order and open-class vocabulary must remain renameable; removing or reversing a premise must change only the consequences licensed by that premise. A broad multiple-choice heuristic would not satisfy this contract.

A deliberately smaller research route accepts only complete monadic categorical propositions—all, none, some, and some-not—and only necessary-conclusion or sufficient-premise questions. It checks every candidate by finite satisfiability: a qualifying candidate makes the premises plus the negated obligation inconsistent; a nonqualifying candidate receives a concrete object-type countermodel. The generic executor is tested with complete renaming, premise ordering, candidate permutation, semantic reversal, and proof replay.

The route may execute a source case only when the question operator, every premise, the conclusion boundary when needed, and all four candidates are inside the declared fragment. Silently ignoring an opaque conditional or compound candidate can reverse the correct choice. Adapter registration and observed coverage belong to the generated row; an unsupported source scope is an engineering gap, not an impossibility result.

The relevant theoretical background includes informal logic, theories of argument, and abstract argumentation frameworks. Those sources motivate representations; they do not replace source-grounded implementation and falsification tests.

Source, rights, and claim boundary

The official encrypted release and repository revision are pinned in the source registry. The official README delivers the data for non-commercial research and publishes the extraction password, but it does not state a separate dataset license identifier. The cache is therefore local and source rows are not redistributed. Cite Weihao Yu, Zihang Jiang, Yanfei Dong, and Jiashi Feng, ReClor: A Reading Comprehension Dataset Requiring Logical Reasoning, ICLR 2020.
