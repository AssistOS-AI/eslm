Executable Symbolic Language Model

A deterministic language system built from explicit symbolic capabilities and declarative knowledge

ESLM is an engineering program for language understanding in which the deployed system is inspectable from input to result. It does not hide facts, rules, task interpretation, or control flow inside opaque weights. It compiles natural-language input into symbolic structures, builds an explicit task frame, selects declared capabilities, executes a bounded plan over trusted runtime code and declarative knowledge packages, and returns the answer together with provenance, unresolved subgoals, and operational evidence.

The deployed runtime is dependency-free, deterministic, offline, and contains no external agent call. The general CLI is a separate operator surface and enables direct-first Language Agent normalization by default: only an UNPARSED utterance may leave the offline boundary, and --no-external-language-agent selects the completely offline profile. A Language Agent may be a general coding agent or a smaller translator focused on ESLM controlled language; the currently supported adapter invokes Codex with the configured gpt-5.3-codex-spark model. Knowledge remains declarative data, agent output remains untrusted, and every accepted rewrite returns through the same parser and reasoner.
