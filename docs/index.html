ESLM Documentation

An executable symbolic language model built as Node.js code

The experiment asks whether a coding agent can transform real language and commonsense sources into auditable executable modules. At runtime ESLM uses no LLM, coding agent, network service, Python, or neural checkpoint. It normalizes an English question, selects an installed knowledge module, executes retrieval or bounded reasoning, realizes an answer, and preserves the evidence that produced it.

The experiment now

The repository contains three different kinds of evidence, and they must not be confused. The promoted core learned narrow deduction and class-property induction patterns from bAbI Tasks 15 and 16. QUICK is authored project knowledge used to test software behavior. Open English WordNet 2025 and ATOMIC 2020 are source-derived KBs compiled from official public releases. Public benchmark results are not mixed with tests that expose those same sources.

Socrates is a man. Is Socrates a man?base modelThe first sentence becomes a session fact and the second retrieves it. The spelling of the name is not pre-registered.
Jhon is a man. Is Jhon going to die?quickThe session classification enters a three-rule mortality chain and returns a depth-3 proof.

Can Penguin fly?quickReturns UNKNOWN. No positive flying fact exists, and open-world reasoning refuses to turn absence into falsehood.

Independent randomized check

The latest reproducible source-KB run used seed 20260810 and tested 700 cases: 100 WordNet definitions, 100 synonym checks, 100 hypernym proofs, and 100 cases for each of four ATOMIC relation families. All 700 passed in eager mode. The combined import and run uses roughly 0.6 GB additional RSS on the recorded machine. ESLM now keeps this fast path when no limit is requested and supports bounded query-selected caches through --memory-mb; representative lazy WordNet and ATOMIC queries are regression-tested. This is a source-exposed integration test, not a public benchmark result. See the machine-readable report for the exact eager measurement and Scale and context for the memory policy.

Conversational regression boundary

The current short catalog contains 134 executable examples, including the questions shown by /examples. A separate generated suite runs 1,000 longer inputs across context with distractors, session retrieval, configured induction, WordNet surface variation, ATOMIC surface variation, and deliberate abstention. The accepted lazy-KB run passed 1,000/1,000 after one WordNet normalization repair. This is an internal regression and stress result, not an open-English or public-benchmark score.
