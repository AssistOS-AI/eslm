Executable Symbolic Language Model

A reviewable foundation for language-driven automation

ESLM is being built to give teams greater control and traceability in language-driven workflows. Its purpose-built symbolic language and Executable Symbolic Language Model concepts organize bounded English requests into inspectable tasks, processing circuits, strategies, evidence, and explicit authority decisions. The repository distinguishes software checks, authored fixtures, generated internal development suites, external development probes, fresh evaluations, annotation or solver tracks, and official tests. They answer different questions and must not be collapsed into one “ESLM accuracy.” A newly assembled report can also contain older receipts; its assembly timestamp is not proof that every benchmark ran again.
