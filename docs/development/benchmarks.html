Benchmark status: what ran, how well, and what remains

A useful benchmark status starts with the execution regime, not the largest percentage. ESLM currently has small internal regression checks, a large project-owned structural development suite, external development probes, and stored fresh-evaluation receipts. Their denominators and claims remain separate.

How to interpret quality

FieldPlain meaning
End-to-end accuracyCorrect cases divided by every eligible case. Abstentions and resource failures remain in the denominator.
Attempt coverageThe fraction for which the system produced a prediction inside the task's answer domain.
Selective accuracyCorrect predictions divided only by attempted predictions. A high value can coexist with low coverage.
Track and input routeWhether the run tested raw English, a source template, an already structured task, an annotation, or only a generic solver. A formula-track success is real solver evidence but not prose-understanding evidence.
Checkpoint stateWhether the stored execution still matches the current implementation. A stale result remains historical evidence and must not be reported as current quality.

Next benchmark work

  • Raw-English companions for structured successes: separately measure whether the frontend can build the formulas, state transitions, relation graphs, and constraints that current adapters already execute.
  • Grounded composition: freeze independent prompts for summaries, explanations, comparisons, and short documents; score factual support, coherence, citation coverage, unsupported claims, and output structure separately.
  • Stronger generated splits: add template-disjoint, vocabulary-disjoint, independently authored, multi-edit, irregular, and genuinely ambiguous cases rather than only adding more rows from the same shapes.
  • New untouched pools: a behavior change cannot reuse an opened fresh partition as unseen evidence. New source versions or newly frozen groups are required.
  • Official comparisons: use the source owner's evaluator when available and keep model, prompt, tools, evidence access, grader, and resource policy aligned.
