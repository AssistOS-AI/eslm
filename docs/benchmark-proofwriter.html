ProofWriter: open-world deduction with explicit support witnesses

ProofWriter provides natural-language theories together with inert logical representations. ESLM deliberately shows two layers: whether its Horn core can solve the logical program, and whether its ordinary language frontend can compile the visible English into that program. Success on the first is not presented as success on the second.

What the current protocol measures

The integrated track samples the main open-world development data across proof depths and all three answer classes. A query is true if its literal is in the independently computed closure, false if the polarity-inverted literal is in the closure, and unknown if neither is derivable. Both polarities yield an inconsistency rather than an arbitrary answer.

Why the dashboard can show a high logical score and full normalization need

SOLVED LOGICAL FORM refers to the official inert representation passed through the generic Horn method. The normalization percentage comes from a separate pass over the natural-language theory: the current frontend rejects its arbitrary predicates, explicit negative statements, and general rules. The Language Agent was not invoked. Translation alone would not replace the missing generic rule-language compiler.

Unscored scope

The current receipt does not score closed-world variants, staged implication enumeration, single-fact abduction, NatLang variants, extended-depth variants, or official test files. Sampling affects evaluation cost only; the complete multi-gigabyte extracted source remains in the ignored cache and no valid row is deleted for size.

Source rights

The official archive contains no dataset-specific license file. The related RuleTaker software repository is Apache-2.0, but that software license is not silently applied to the archive. Local research evaluation continues without plaintext redistribution while archive-specific terms are clarified with AI2.
