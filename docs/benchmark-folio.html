FOLIO: natural arguments paired with first-order formulas

FOLIO separates two difficult questions: can the system interpret relatively natural language as first-order structure, and can it decide the resulting formula theory? ESLM reports the official-formula track and direct-language coverage separately so formula execution cannot masquerade as language understanding.

Current measurements: Read the generated FOLIO rows on the evaluation dashboard or inspect the raw v2 report. Compilation counts, solver outcomes, and route coverage are report-owned.

What the protocol measures

The formula track parses quantified premises and conclusions into typed ASTs, grounds the supported fragment over named constants, and asks finite entailment for the three-way label. Language evidence is split three ways. The unchanged Stage A runtime receives the original prose and measures deployable direct coverage. A development-only quantified-English candidate attempts to compile every premise and conclusion into typed formulas; a case executes only when every sentence succeeds. A diagnostic query track compiles only the natural-language conclusion while using official premise formulas solely to declare the available predicate and constant vocabulary. That query track never sees conclusion FOL or the answer label, but it is still not direct language understanding and is reported separately.

How to read the outcomes

SOLVED means a finite method returned a decision; correctness is still oracle agreement. UNSUPPORTED FORMULA identifies malformed or unsupported source syntax. RESOURCE LIMIT identifies incomplete search. Grounded theories beyond the small exhaustive atom bound may pass to scalable Boolean entailment when they remain inside its contract. INCONSISTENT CONTEXT means no finite assignment satisfies all grounded premises, so classical explosion is deliberately not used. A route that did not execute has no normalization or accuracy metric.

Evidence boundary

The pinned v0.0 validation file is development-visible, and its official test set is unreleased, so it cannot support a fresh test claim. The corrected Hugging Face v2 source is a distinct gated source and must be authorized, pinned, and validated before comparison. The report says which source and routes actually ran.

Controlled quantified-English candidate

The generic candidate recognizes declared constructions such as universal class implication, existential predication, universal negation, named unary predication, explicit Boolean composition, and bounded generalized conditionals. Adapter-owned resolvers map source surface predicates and constants to typed symbols; the generic composer sees grammatical operators and resolver outcomes, never benchmark identity, record identity, or oracle values. A missing mapping returns UNSUPPORTED; competing mappings return AMBIGUOUS; excessive composition returns RESOURCE_LIMIT. Negation and quantifier scope remain explicit in the AST instead of being flattened into token overlap.

Formula execution uses two generic methods under one semantic contract. Small grounded theories use exhaustive finite assignment enumeration. If their atom count exceeds that method's declared threshold, the same validated formulas pass to query-directed Tseitin-CNF compilation and deterministic DPLL. That fallback returns a checked conflict certificate or complete countermodel; it does not raise the exponential enumeration limit, remove formulas, sample assignments, or drop a source row. The live report records both routes separately from natural-language compilation.

The query diagnostic may compile only the natural-language conclusion while taking predicate and constant vocabulary from official premise annotations. That assistance makes the route diagnostically useful but prevents it from being called direct natural-language accuracy. The report keeps sentence compilation, complete-case execution, and query-only outcomes separate.

Promotion requires a declared parser route, broader metamorphic coverage, and untouched evidence that actually exercises that route. The existence of a development compiler is not itself deployed-frontend coverage.

What remains

Remaining language clusters include correctly scoped predicate, noun-phrase, disjunctive, and exclusive-or coordination; conditional and relative-clause boundaries; binary argument and reference resolution; and predicates absent from the premise vocabulary. The formula track must also preserve malformed or unsupported annotations and inconsistent named-domain contexts as separate statuses. Progress requires explicit semantics for those constructions and domain assumptions; it cannot come from copying validation formulas or labels into runtime dispatch.
