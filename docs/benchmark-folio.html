FOLIO: natural arguments paired with first-order formulas

FOLIO separates two difficult questions: can the system interpret relatively natural language as first-order structure, and can it decide the resulting formula theory? ESLM reports the official-formula development track and direct-language coverage separately so formula execution cannot masquerade as language understanding.

What the protocol measures

The formula track parses quantified premises and conclusions into typed ASTs, grounds the supported fragment over named constants, and asks finite entailment for the three-way label. Language evidence is split three ways. The unchanged Stage A runtime receives the original prose and measures deployable direct coverage. A development-only quantified-English candidate attempts to compile every premise and conclusion into typed formulas; a case executes only when every sentence succeeds. A diagnostic query track compiles only the natural-language conclusion while using official premise formulas solely to declare the available predicate and constant vocabulary. That query track never sees conclusion FOL or the answer label, but it is still not direct language understanding and is reported separately.

How to read the outcomes

SOLVED means a finite method returned a decision; correctness is still oracle agreement. UNSUPPORTED FORMULA identifies malformed or unsupported source syntax. RESOURCE LIMIT would identify incomplete search, but grounded theories beyond the small exhaustive atom bound now fall through to scalable Boolean entailment rather than failing merely because they are larger. INCONSISTENT CONTEXT means no finite assignment satisfies all grounded premises, so classical explosion is deliberately not used. The current development candidate did not rerun the deployed runtime frontend, so the dashboard does not invent a normalization percentage for that unexecuted route.

Evidence boundary

The pinned v0.0 validation file is executed completely, but it is development-visible. Its official test set is unreleased, so no fresh claim is possible. The corrected Hugging Face v2 source is a distinct gated source and must be authorized, pinned, and validated before comparison.

Controlled quantified-English candidate

The generic candidate recognizes declared constructions such as universal class implication, existential predication, universal negation, named unary predication, explicit Boolean composition, and bounded generalized conditionals. Adapter-owned resolvers map source surface predicates and constants to typed symbols; the generic composer sees grammatical operators and resolver outcomes, never benchmark identity, record identity, or oracle values. A missing mapping returns UNSUPPORTED; competing mappings return AMBIGUOUS; excessive composition returns RESOURCE_LIMIT. Negation and quantifier scope remain explicit in the AST instead of being flattened into token overlap.

Formula execution uses two generic methods under one semantic contract. Small grounded theories use exhaustive finite assignment enumeration. If their atom count exceeds that method's declared threshold, the same validated formulas pass to query-directed Tseitin-CNF compilation and deterministic DPLL. That fallback returns a checked conflict certificate or complete countermodel; it does not raise the exponential enumeration limit, remove formulas, sample assignments, or drop a source row. The live report records both routes separately from natural-language compilation.

The latest complete development audit compiles 545 of 1,292 sentence slots. It produces 383 exact formulas among the 1,279 parseable official sentence annotations. Requiring every premise and conclusion to compile yields 4 correct complete cases from 204. The separate query diagnostic compiles 108 of 204 conclusions and scores 75/204 while using only the predicate and constant vocabulary declared by the official premise annotations. That assistance makes the query result diagnostically useful but prevents it from being called direct natural-language accuracy.

This module is not yet registered in the deployed parser. FOLIO v0.0 exposes no untouched labeled test or language-only split with which to justify promotion, so its current value is development measurement and reusable metamorphic tests. The live report gives exact sentence, complete-case, and query-only counts without conflating them.

What remains

Remaining language clusters include correctly scoped predicate, noun-phrase, disjunctive, and exclusive-or coordination; conditional and relative-clause boundaries; binary argument and reference resolution; and predicates absent from the premise vocabulary. The formula track still has five malformed or unsupported annotations and 24 named-domain contexts that the finite interpretation reports as inconsistent. Progress requires explicit semantics for those constructions and domain assumptions; it cannot come from copying validation formulas or labels into runtime dispatch.
